# public/data

Offline data artifacts shipped inside the extension. They are generated from
local inputs (not committed) by the scripts below and **are** committed here
because they ship with the extension.

| File | Generated by | Source | License |
| --- | --- | --- | --- |
| `ecdict.json` | `pnpm build:ecdict` (`scripts/build-ecdict.ts`) | [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) via `data/ecdict.csv` | MIT repo (third-party CC-BY ambiguity noted in `NOTICE`) |
| `lemmas.json` | `pnpm build:ecdict` | ECDICT `lemma.en.txt` via `data/lemma.en.txt` | MIT |
| `collocations.json` | `pnpm build:collocations` (`scripts/build-collocations.ts`) | [opensubs-collocations](https://huggingface.co/datasets/vladvlasov256/opensubs-collocations) via `data/en.jsonl` | CC-BY 4.0 — OpenSubtitles, Lison & Tiedemann 2016 |

Input files live in the gitignored `data/` directory. Scripts accept
`ECDICT_CSV`, `LEMMA_TXT` and `OPENSUBS_JSONL` environment variables with
`data/...` defaults.

The content entrypoint fetches these files with
`chrome.runtime.getURL('data/<file>')`; `wxt.config.ts` registers `data/*` as a
`web_accessible_resource` on YouTube origins.
