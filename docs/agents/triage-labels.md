# Triage 标签

这些技能用五个规范 triage 角色说话。本文件把角色映射到本仓库 issue tracker 里实际使用的标签串。

| mattpocock/skills 里的标签 | 我们 tracker 里的标签 | 含义                           |
| -------------------------- | --------------------- | ------------------------------ |
| `needs-triage`             | `needs-triage`        | 待维护者评估                   |
| `needs-info`               | `needs-info`          | 在等报告者补充信息             |
| `ready-for-agent`          | `ready-for-agent`     | 规格已完整，可交给 AFK agent   |
| `ready-for-human`          | `ready-for-human`     | 需要人来实现                   |
| `wontfix`                  | `wontfix`             | 不做                           |

技能提到某个角色时（例如“打上 AFK-ready 的 triage 标签”），就用表里对应的标签串。

要换成本仓库已有的命名，只改“我们 tracker 里的标签”这一列。
