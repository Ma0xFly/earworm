# 中文翻译与搭配标注共用一条 LLM 批处理管线

YouTube 中文轨道多为机翻（「Google 图书」式不本土化的来源），且不存在明确开放许可的通用英语搭配库（COCA/BNC 衍生数据禁分发、教材有版权、PHaVE 许可不明）。决定：中文字幕一律由自有 OpenAI 兼容 LLM 翻译（默认本机 magpie 网关），永不使用 YouTube 中文轨道；整轨批量预翻译，prompt 携带视频标题、频道与前后句上下文，同批让模型输出每句的搭配 span，供高亮与点词查短语使用；结果按 videoId + 轨道指纹缓存。另打包清洗后的 OpenSubtitles CC-BY 4.0 二元搭配表（15k 条清洗至约 1 万条，~600KB）作离线高亮基线：字幕加载即高亮、零 token；LLM 标注负责三元及以上短语、上下文搭配与弹窗释义；两路 span 取并集，重叠时 LLM 优先。

## Consequences

翻译与搭配共用同一缓存 schema 与 prompt 契约，改动其一即牵动整体；懒翻译（只翻当前句）给不了本土化所需的上下文，故不采用。
