# 删除字幕侧栏，交互收敛到 overlay + 控制栏快捷开关

侧栏（F2）已实现并经 #29 实测验收，但用户实际使用反馈「不是很有用」：句导航 a/s/d 已覆盖跳转，overlay 点词已覆盖查词，侧栏信息与 overlay 冗余。决定：整体删除 features/sidebar（含测试与专用选择器），保留 overlay + a/s/d + 词典弹窗；高频控制（总开关/blur/导出/设置入口/翻译状态）收敛到注入播放器控制栏的快捷开关（logo 按钮 + 快捷菜单，Captionary 先例，避开全屏键热区）。

## Consequences

嵌套 shadow root 的 blur 分支随之删除；未译标记+重试移入快捷菜单；#29 的文档流布局投入为沉没成本，记录于此防止未来「为什么刚建好就删」的疑问。
